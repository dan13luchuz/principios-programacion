# Principios de Programación

Este repositorio contiene ejercicios, prácticas y trabajos realizados durante el curso de Principios de Programación.

## Contenido

### Ejercicios

La carpeta `ejercicios` contiene las soluciones desarrolladas durante el curso.

### Prácticas

La carpeta `ejercicios/practicas` contiene diferentes prácticas realizadas en Python.

### Trabajo en clase

La carpeta `ejercicios/trabajo_en_clase` contiene ejercicios desarrollados durante las clases.

## Herramientas utilizadas

- Python 3
- Visual Studio Code
- Git
- GitHub
