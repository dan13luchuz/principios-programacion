# Principios de Programación

Este repositorio contiene ejercicios, prácticas, diagramas y trabajos realizados durante el curso de **Principios de Programación**.

El objetivo del repositorio es mantener organizadas las actividades del curso y mostrar el progreso realizado durante las diferentes semanas.

## Organización del repositorio

La carpeta principal de ejercicios está dividida en dos secciones:

```text
ejercicios/
├── semanas/
└── trabajo_en_clase/
```

### Semanas

La carpeta `ejercicios/semanas` contiene las prácticas y actividades organizadas por semana.

Actualmente incluye:

- `semana1`: hardware, software, algoritmos y diagramas de flujo.
- `semana2`: variables, entrada de datos y cálculo de compras.
- `semana3`: revisión de estilo, code review y corrección de descuentos.
- `semana4`: flujo condicional, acceso a eventos y tienda de videojuegos.
- `semana5`: operadores lógicos, permiso para conducir, descuentos y beca estudiantil.
- `semana6`: análisis de flujo condicional y prueba de escritorio.
- `semana7`: uso de ciclos `while`, inventario de una tienda, acumuladores, contadores y casos de prueba.

### Trabajo en clase

La carpeta `ejercicios/trabajo_en_clase` contiene ejercicios desarrollados durante las clases para practicar diferentes conceptos de programación en Python.

Los diagramas se encuentran guardados en formato PNG dentro de las carpetas correspondientes a cada semana.
